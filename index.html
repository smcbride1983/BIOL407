Data notes and unresolved entries

The latest supplied table replaces earlier measurements. WHC is converted from g/g to %. Respiration is expressed in nmol CO₂/g soil/h, converted from µmol by multiplying by 1,000. NH₄ and NO₃ units need confirmation. Suspect precipitation, VPD (including Caledon), and Socorro elevation are excluded from all analyses. Values remain visible in profiles. Merced’s measurements are missing in the new table and are not carried forward. Missing values are never zero. Habitat labels follow the supplied website; the coastal swale is nonforest. Confirm classifications before formal inference. Rounded respiration values limit precision; a supplied 0.00 is retained as zero.
